## 🚀 How to Deploy to GitHub Pages

1. **Create a GitHub Repository**:
   - Go to [GitHub](https://github.com/new) and create a new **public** repository named `portfolio-website` (or `coursera-portfolio`).

2. **Upload Files**:
   - Click **uploading an existing file**.
   - Drag and drop: `index.html`, `style.css`, `script.js`, and `README.md`.
   - Commit with message: `Initial commit: Ujjwal Singhal portfolio`.

3. **Enable GitHub Pages**:
   - In GitHub, go to **Settings** &rarr; **Pages** (under "Code and automation").
   - Under **Build and deployment > Source**, select **Deploy from a branch**.
   - Select branch: `main` and folder: `/(root)`, then click **Save**.

4. **Get Your Live URL**:
   - Your site will be published at:  
     `https://<your-username>.github.io/<your-repo-name>/`
   - Submit this URL for your Coursera peer review!
